# Contributing

[简体中文](CONTRIBUTING.zh-CN.md)

Read [development](docs/en/development.md), the [runtime contract](docs/en/contract.md) and shared [product principles](CONSTITUTION.md). Use [releasing](docs/en/releasing.md) when preparing artifacts.

Sign commits with `git commit -s` for DCO. In the PR, describe the change, checks run and remaining gaps. Cross-repository changes identify both source commits, artifacts and paired PRs.
