浏览器 TLS carrier 是测试工具，无平台授权；测试 API key 无效，不发模型请求。
重启验证为正常进程停止/重开，不等于生产 stop/start API 或节点故障恢复。
样本无 NetworkPolicy，不能以它证明跨用户隔离。B 的生产模板外围 SA/namespace/策略核验仍待实现。

构建中修正了一处共享 accesscontract 对旧常量包的编译依赖；B 删除旧路径时移出仍需的 cookie/header 边界。
kind 首次导入后只有 tag，digest 引用触发拉取失败，补齐同内容 digest tag 后 Ready；未推送 registry。
一次默认工作区断言在已由 dshprobe 注册 workspace 后得到空初始化结果，属于原生仅首次初始化语义；未据此报告集群默认工作区创建通过。

## 接口与后续所有权

[契约及精确路径表](../design/environment-contract.zh-CN.md) 固定
`createAgentEnvironmentRuntime(options: EnvironmentRuntimeOptions)` 为 B 待实现入口。
A 包只有真实模板、类型和错误类，没有伪造的 lifecycle factory。
connect 的 signal 覆盖整个 HTTP/WS 生命周期；StopUnverified 阻断 start/delete。
平台保存 owner/CR UID/唯一 PVC UID，未知结果只查原 key，资源删除保留 PVC。

B 独占 runtime 新适配及旧 Cell/Operator/snapshot/standalone 清除；C 独占平台源码/包锁/vendor；
D 仅 charts、integration/installation、docs/installation；D 不复制 runtime 模板。
当前旧 Cell 代码和平台旧路径是分阶段待删除内容，不是保留的兼容模式。
A→B→E 顺序移交唯一集群写入权。
